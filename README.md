# DataPrivacy

面向 Android APK 与 iOS IPA 的隐私合规分析流水线：从敏感 API、调用方、启动链路、请求字段和上传端点定位数据处理线索，再结合冷启动及隐私政策同意前后的运行证据，辅助研发排查、隐私合规审查与整改复测。

本仓库提供两个 Codex skill、分析脚本与报告生成工具。静态结果说明代码具备什么能力；动态证据说明特定版本、设备和测试场景中实际发生了什么。当前本地环境已验证模拟器启动及部分基础采集，**尚未完成真实 APK/IPA 的端到端扫描验收**；具体状态见 [PROGRESS](docs/PROGRESS.md)。

| Skill | 入口 | 主要工具 |
| --- | --- | --- |
| Android | [apk-scan-pipeline-meta](skills/apk-scan-pipeline-meta/SKILL.md) | Python、JDK 21、jadx、本地 SQLite 服务 |
| iOS | [ipa-scan-pipeline-meta](skills/ipa-scan-pipeline-meta/SKILL.md) | Python、JDK 21、Ghidra、MobSF；动态分析另需 macOS/Xcode/设备 |

## Android：APK 隐私行为分析

### 静态分析

- **敏感 API 与调用位置**：基于 jadx 反编译源码识别设备标识、位置、通讯录、相机、麦克风、剪贴板等敏感能力，定位调用方、类、方法和代码片段。
- **一方业务与第三方 SDK 归属**：根据当前 APK 的包名和代码结构推导一方前缀，聚类识别 SDK，并追溯一方业务对 SDK 的调用；不预设某个厂商始终属于一方。
- **调用链与启动链路**：上溯敏感调用的业务入口，分析 `Application.onCreate()` 等启动入口到 SDK 初始化、敏感 API 的可见路径，识别权限检查、隐私同意开关和包装层守卫。
- **网络请求字段与端点**：提取 URL、域名及请求构建字段，关联字段所在类、方法与 SDK，形成“调用方 → 敏感能力 → 请求构建 → 上传端点”的证据线索。优先使用 SDK 包内源码直接核验，邻近归集结果单独标注。
- **配置与扩展代码**：分析 Manifest 权限、组件和包可见性 queries；补充 Native `.so` 敏感特征、加载线索及 JSBridge 敏感能力暴露。

调用链恢复受混淆、反射、动态加载、Native 实现和服务端配置影响，不能保证覆盖全部路径。静态字段名或 URL 命中，不等于已经采集或上传，也不代表完成了任意数据的端到端污点追踪。

### 动态检测：冷启动与同意前后对比

测试围绕“首次安装/清除测试数据 → 冷启动未同意 → 拒绝或关闭弹窗 → 明确同意 → 使用相关功能”分阶段进行；隐私政策同意与系统权限授权分别记录，比较敏感 API 访问、SDK 初始化和网络请求的发生时点、频次及可见字段。

| 取证方式 | 可以回答的问题 | 前置条件 |
| --- | --- | --- |
| ADB、截图、logcat | 弹窗何时出现、用户如何操作、应用输出了哪些可见日志 | 模拟器或开启 USB 调试的真机；日志完整性取决于应用 |
| 网络采集/代理 | 访问哪些端点；明文可见时上传了哪些字段 | 需配置采集链路；HTTPS 解密取决于证书信任、证书固定和应用网络栈 |
| API 插桩、调试日志或测试埋点 | 敏感 API 是否实际调用、调用堆栈、可观测参数或返回值 | 需另配 Frida 等插桩或应用侧测试能力，并验证覆盖范围 |

**Android 当前交付以静态流水线为主；动态阶段是待接入并验收的取证流程，尚无已验收的通用 API Hook 与同意前后自动对比流水线。** 不安装 Frida 也可做基础观察；仅凭截图、logcat 或加密流量，无法保证识别所有敏感 API 调用及实际出值。Debug 包有助于调试和抓包，正式包应另行复测并记录行为差异；真机可减少模拟器差异。

## iOS：IPA 与模拟器构建隐私行为分析

### 静态分析

- **包结构与声明**：解包、解析 Mach-O 并检查加密状态；结合 MobSF 分析 Info.plist 权限用途说明、ATS、URL Scheme、依赖库及域名线索。
- **敏感 API 与调用链**：使用 Ghidra 分析主程序及独立 Framework，定位敏感 API、类、方法、调用方和反编译片段；覆盖位置、通讯录、相机/相册、麦克风、IDFA/IDFV、剪贴板等类别。
- **SDK 与启动线索**：结合 Bundle ID、类名前缀和 Framework 边界分析归属，检查 `+load`、AppDelegate 等启动阶段调用，以及隐私同意开关和 WKWebView/JSBridge 线索。
- **字段、端点与声明核对**：提取二进制中可见的 URL、字段字符串和请求构建线索，解析 `PrivacyInfo.xcprivacy` 的收集声明、追踪标记及必要理由 API 声明，供后续与运行证据交叉核对。

iOS 的字段与端点关联受二进制可恢复信息限制，不能承诺与 Android 源码分析相同的完整度。深度静态分析要求目标 Mach-O 可解析且未加密，须检查实际加密标记，不能仅按 TestFlight、企业签等分发渠道判断。

### 动态检测：运行时证据关联

已有动态证据解析与报告注入脚本，可按冷启动未同意、权限交互、同意后使用等阶段，关联截图、系统/应用日志、流量及应用侧 netlog，生成接口、敏感字段与同意时序摘要，并回填细节报告、导图和风险报告。

字段级明文和调用时序需要可用的测试日志、埋点或其他取证能力；普通加密流量不能直接还原请求内容。当前 macOS/Xcode/iOS Simulator 已有启动和截图验证，目标应用动态流程仍待真实样例验收。模拟器必须使用与其平台和架构匹配的构建，普通真机 IPA 不能直接运行；越狱真机的部署与插桩须另行配置和验证。

## 参考法规、标准与商店规则

报告围绕告知与同意、最小必要、敏感个人信息、第三方 SDK 披露、启动行为及数据对外提供等检查点，关联仓库内 `law_clauses.py` 与 `store_clauses.py` 的条款库。主要参考包括：

| 类型 | 参考依据与使用范围 |
| --- | --- |
| 法律 | [《中华人民共和国个人信息保护法》](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)：处理目的、最小必要、告知、同意及敏感个人信息等 |
| App 治理依据 | [《App违法违规收集使用个人信息行为认定方法》](https://www.cac.gov.cn/2019-12/27/c_1578986455686625.htm)、[《常见类型移动互联网应用程序必要个人信息范围规定》](https://www.cac.gov.cn/2021-03/22/c_1617990997054277.htm)：结合业务功能核查采集范围和同意机制 |
| 推荐性国家标准 | GB/T 35273—2020《信息安全技术 个人信息安全规范》：作为个人信息处理活动的技术评估参考，具体条款及适用版本需复核 |
| 专项整治要求 | [工信部 App 侵害用户权益专项整治通知](https://wap.miit.gov.cn/jgsj/xgj/wjfb/art/2019/art_a2fc4363c4344a0e94831fd7bcf318d2.html)等：辅助梳理违规收集、超范围收集及 SDK 相关检查点 |
| Android 商店规则 | [Google Play User Data Policy](https://support.google.com/googleplay/android-developer/answer/10144311?hl=en)：适用于 Google Play 分发场景；其他安卓商店需另补其具体规则 |
| iOS 商店规则 | [App Store Review Guidelines 5.1](https://developer.apple.com/app-store/review/guidelines/#privacy)：隐私政策、数据收集使用与共享等审核要求 |

法律、推荐性标准与商店审核规则分别标注，不混作同一效力层级。仓库条款库含历史整理内容，尚未逐条完成法律原文、编号和现行适用性的审校；正式交付应核对版本、具体业务场景及处理依据，不直接把库内摘要当作法规原文。技术发现辅助人工合规判断，不自动等同违法结论或商店拒审结果。

## 最终交付产物

| 产物 | 主要内容 |
| --- | --- |
| 风险推断报告（HTML） | 问题或风险、适用场景、证据、参考条款与研发/合规整改建议；作为合规判断的集中入口 |
| 敏感行为导图（HTML） | 可恢复的启动路径、业务调用链、敏感能力、SDK 与字段/端点关系 |
| 技术细节报告（HTML） | Android Manifest 或 iOS Info.plist、SDK 清单、敏感调用位置、代码证据、Native/Framework 与质量检查结果 |
| 综合入口 | Android 提供综合报告入口，串联风险、导图和细节报告；iOS 按现有生成器分别交付，综合入口需核对实际产物 |
| 动态证据与结构化结果（完成采集时） | 分阶段截图、日志、流量或 netlog、可见字段及时间线；iOS 可生成动态摘要 JSON 并注入报告，Android 汇总与自动化仍待接入 |
| 范围与复测记录 | 样本版本/哈希、设备与系统、测试阶段、已覆盖能力、跳过项、未验证项、QC 结果和复测结论；随实际任务记录 |

交付时区分“静态发现/待运行时确认”“动态观察到的事实”“结合业务与规则确认的问题”。未观察到不代表不存在；只有对应证据与适用条件充分时才提出确定性整改结论。完整交付应列出实际生成的文件及验证范围，不能用语法检查通过替代完整扫描通过。

## 安装 skill

在 Windows PowerShell 中，将仓库克隆到任意本地目录后，在仓库根目录执行：

```powershell
$skillRoot = Join-Path $env:USERPROFILE '.codex/skills'
New-Item -ItemType Directory -Force $skillRoot | Out-Null
Copy-Item ./skills/apk-scan-pipeline-meta $skillRoot -Recurse
Copy-Item ./skills/ipa-scan-pipeline-meta $skillRoot -Recurse
```

已有同名 skill 时，先比较或备份原目录。完成后重启 Codex，使其发现 skill。以上仅安装 skill 文件，外部分析工具须另外安装。
