# 分发说明与已知限制

源码来自用户提供的 `apk-scan-pipeline-meta-v3.zip` 和 `ipa-scan-pipeline-meta.zip`，以本机已安装版本为基础收录。已去掉当前机器的部署路径说明，原作者的示例 macOS 用户改为 `macos_user`。

- 原包未提供文档提到的 `bundle/` 离线工具，不包含 jadx/JDK/SDK/MobSF 等完整安装资源。
- APK 旧 `check_env.py` 会要求已废弃的 TOKEN 和未分发的辅助脚本，属于已知遗留问题。不要为通过该检查配置内网凭据或伪造通过结果。
- APK 扫描参数以 `scan_decompiled.py --help` 为准，文档中部分旧参数不匹配。
- iOS 脚本仍有示例路径、WSL 发行版和 SSH 用户假设；动态门禁尚需按实际 macOS 账号配置。示例用户名不代表已创建账户。
- 静态分析需要可解析的未加密 Mach-O。不能仅按企业签、TestFlight 等渠道判断加密状态，应检查实际包。
- 普通 iPhone IPA 不能直接作为 iOS 模拟器构建运行；需匹配构建或合适真机。
- 本仓库没有新增开源许可证授权；随附第三方代码的权利和许可归各自权利人，不应据此假定允许任意再分发。
- 只提交源码、说明和脚本；不提交本地服务 secret、认证信息、输入样本、数据库、日志、虚拟磁盘或扫描报告。
